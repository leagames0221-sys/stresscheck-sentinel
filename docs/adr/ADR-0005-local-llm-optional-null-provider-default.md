# ADR-0005: LLM はローカル (Ollama) の任意層とし、既定は生成なし

- Status: Accepted
- Date: 2026-08-21

## Context

指針は、結果通知に「セルフケアの内容」を含めることが望ましいとしている。この文面は
定型文でも成立するが、回答の内容に沿って書き分けられる方がよい。LLM が役に立つのはここだけである。

一方で、この用途に外部 API を使うと次が同時に起きる:

- 従業員の心理的負担に関する回答が事業場の外へ出る (`docs/spec/requirements.md` R7-2 と正面衝突)。
- クレジットカードが要る。
- API キーの管理が要る。
- 提供者の都合でモデルが変わり、**評価済みの挙動が黙って変わる**。

さらに、モデルが無い環境で動かないツールは、産業医の PC では動かないツールである。

## Decision

**LLM は差し替え可能な任意層とし、既定は `NullProvider` (生成しない)。**

- `LLMProvider` を ABC として定義し、実装は 2 つ:
  - `NullProvider` — `prompts.yaml` の `fallback_text` を返す。**既定**。
  - `OllamaProvider` — `urllib` で `http://localhost:11434/api/chat` のみを叩く。
- 選択は環境変数 `LLM_PROVIDER` (未設定 / `null` → Null、`ollama` → Ollama)。
  コードの分岐ではなく環境で切り替わる = 既定の安全側が「設定しないこと」で得られる。
- **接続先はコンストラクタで制限する**。「localhost にしか出ない」を README の約束ではなく
  コードの制約にしてある。
- 用途は文面生成と平易な言い換えに限る。**採点・高ストレス判定・危機対応には一切使わない**。
- LLM の出力は、利用者に見せる前に必ず禁止表現 lint (ADR-0007) を通る。

## Alternatives considered

| 代替 | trade-off |
|---|---|
| **クラウド API (OpenAI / Anthropic 等)** | 出力品質は最も高い。だが上記のとおり R7-2 (外部送信ゼロ) と正面から衝突し、課金と鍵管理が発生する。品質の差は、この用途 (数百字のセルフケア文面・実施者が必ずレビューする) では決定的でない。 |
| **Cloudflare Workers AI の無料枠** | 無料枠があり、クレカ不要で始められる。しかし推論は外部で走る = 送信内容が事業場の外に出る事実は変わらない。「無料だから」は R7-2 の判断を変える理由にならない。 |
| **既定を `OllamaProvider` にする** | 体験は良い。だが Ollama が無い環境では起動直後に落ちるか、毎回タイムアウトを待つことになる。**既定は「モデルが無くても全機能が動く」側に置く**方が、配布物としての性質が良い。Ollama を入れた人だけが 1 つ環境変数を足す。 |
| **LLM を使わず定型文だけにする** | 最も単純で、安全性も最大。しかしそれではプロンプトの版管理・生成物の評価・judge の一致度といった、このリポジトリが主題にしている問題が一切現れない。**LLM を「使う場所」と「使わない場所」を線で分けて見せること**が目的なので、線の片側だけを実装しても示せない。 |

## Consequences

- **良い**: 既定でモデル不要・ネットワーク不要。テストも CI も、モデルなしで全部通る。
- **良い**: 課金要素がゼロのまま「LLM を含むシステムの評価」を実演できる。
- **良い**: 差し替え点が 1 つ (`get_provider()`) なので、将来別のローカル推論を足す時に
  触る場所が決まっている。
- **悪い**: 文面の品質はローカル小型モデルの水準になる。実測でも、judge 2 本のうち 1 本が
  「具体的な行動の提案が無い」として 10 件中 4 件を落としている
  (`docs/evidence/EVALS_RUN_2026-08-21.md` §4)。品質を上げたければモデルを替える話になり、
  替えたら評価を回し直す — その手順自体がこのリポジトリの成果物である。
- **悪い**: 生成を有効にした場合の再現性は、モデルとバージョンに依存する。だからこそ
  **安全性の可否は生成側ではなく決定論ゲートに置いた** (ADR-0006)。
